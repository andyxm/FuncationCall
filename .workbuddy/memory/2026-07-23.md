## assistant_ticket_bot-3.py 的 Docker 报错
- 用户运行 bot-3 报 `Docker is not installed`，但代码里没直接写 docker。
- 根因：第216行 `function_list=['exc_sql', 'code_interpreter']`，`code_interpreter` 是 qwen_agent 内置工具，**内部依赖 Docker 容器跑沙箱 Python**，初始化即检查 → 报 Docker 缺失。
- 修复：移除 `code_interpreter`（本脚本绘图已在 `exc_sql.call` 内用 matplotlib 本地完成 `generate_chart_png`，`system_prompt` 也要求原样输出图片，故该工具多余）。
- 同款预防修复（与 bot-1 一致）：`parameters` 旧式列表 → 标准 JSON Schema 字典；`call` 的 `json.loads` 加正则容错兜底（防 `JSONDecodeError` 中断对话）。
- 验证：`py_compile` 通过；`init_agent_service()` 成功（`助手初始化成功！`，`function_map=['exc_sql']`），不再要求 Docker。
- 注：bot-3 连接串已是 `mysql+pymysql://` + `text()` 包裹（无需再改）；运行前同样需 `taskkill` 旧进程后重启。图片以相对路径 `image_show/xxx.png` 返回，若 WebUI 不显示本地图片再单独处理。
